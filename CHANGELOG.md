# Changelog

## 0.8.1-dev - 2026-11-03

- Improve cancellation and stale-result handling, input/resource cleanup, and bounded log, Run Record and threshold-analysis processing without changing established measurement formulas.
- Update the pinned SDK integration and its verifier contracts; preserve public Viewer/Host boundaries and existing failure checks.
- Refresh the synthetic inspection media. Dock-menu return and four distinct large-origin LAS picks remain unconfirmed. This development source delivery does not claim full audit, installation compatibility or physical measurement acceptance.

## 0.8.0-dev — 2026-10-30

- Added nine-point surface compensation and exact downstream Warpage/Thickness height-map inputs.
- Restored linked results, textures and command state across run, cancellation/retry and save/reopen.
- Added browse actions and compact path display for recipe and Exchange inputs while preserving full saved paths.
- Corrected recipe-load and save/reopen recovery, signed-height result persistence, and recorded step reasons in reports.
- Updated the English/Korean user documentation and included required Shell dependency notices.

This is a development source update; it is not a binary release, deployment or production qualification.


## 0.7.1-dev — 2026-10-17

- Reduced repeated C3D measurement readiness preparation and unnecessary teaching
  selection list updates.
- Corrected selected-ROI redraws, parameter validation and nested display popups.
- Preserved Graphite resources in floating panels and corrected verification
  failure exit codes.

## 0.7.0-dev — 2026-10-16

- Reorganized recipe teaching, settings, viewer panes, validation, and records;
  improved recipe-open and per-file result-save recovery.
- Added aligned 2D appearance images on C3D surfaces with source-bound display
  preferences, visibility control, validation on restore, and GPU cleanup.
- Limited numeric presentation to two decimal places while preserving raw
  calculation and storage precision. Viewer Host API adds optional display
  operations in version `1.2`.

This is a development source update. It does not publish a binary release or
qualify a production installation.

## 0.6.0-dev — 2026-10-03

- Updated Graphite controls, tool settings, input/output nodes, viewer and height
  profiles, results, recipe management, and tool labs.
- Improved invalid numeric-draft handling, non-finite height-cursor rejection,
  and small-panel access to required coordinate and profile controls.
- Included the current pinned integration package pair and refreshed public
  source-build and usage documentation.

This is a development source update. Viewer Host API `1.1` remains unchanged.
Native mouse/keyboard, popup, OpenGL, 100%/125% scaling, and complete operational
verification remain separate. No binary release or deployment is implied.
