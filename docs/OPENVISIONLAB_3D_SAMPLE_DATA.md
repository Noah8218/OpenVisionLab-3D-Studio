# OpenVisionLab 3D Sample Data

Only redistributable public samples and procedurally generated fixtures may be
committed to this repository.

## Primary C3D sample

| File | Purpose |
| --- | --- |
| `3D/Samples/ThicknessCouponV1/thickness-coupon-v1.C3D` | Default public C3D, ROI teaching, eight-pad Thickness, Source Quality, Height Image, and Runner replay |
| `3D/Samples/ThicknessCouponV1/source-height-preview.png` | Deterministic human-review preview |
| `3D/Samples/ThicknessCouponV1/ground-truth.json` | Exact source identity, coverage, ROIs, and expected Thickness values |
| `3D/Samples/ThicknessCouponV1/inspection-recipe.ov3d-recipe.json` | Schema `1.5` eight-step Thickness recipe |

The C3D is `1280 x 840`, contains `908,436` valid and `166,764` missing
cells, and has SHA-256
`D879FC9E40678762214E8C3FBEA01F5C9A309701DAAEAD448067E563C5B502F8`.
It is generated by:

```powershell
python scripts/generate-thickness-coupon-sample.py `
  --output 3D/Samples/ThicknessCouponV1
```

The unit `raw-height` is deliberately non-physical.

## Additional synthetic validation

`3D/SyntheticValidation/AffineInspectionPlateV1` is the deterministic
multi-tool affine/reference validation package.

## Public format samples

`3D/PublicSamples` contains the repository's redistributable glTF, STL, LAS,
LAZ, and intentionally invalid parser fixtures. Their licensing and source
notes remain in that folder.

## Prohibited sample content

Do not commit:

- customer or employer scans;
- captured production parts without an explicit redistribution license;
- source-specific filenames, serial IDs, hashes, screenshots, or ROI
  coordinates derived from non-public data;
- a renamed or transformed copy of a non-public source;
- AI images as numeric ground truth.

For generated samples, record the generator, deterministic hash, known values,
and a non-metrology boundary. See
`OPENVISIONLAB_3D_SYNTHETIC_THICKNESS_SAMPLE_MIGRATION_20260728.md`.
